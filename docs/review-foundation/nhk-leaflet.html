Problem

レビュー情報が制作工程の途中で散る

  • 動画はDropbox、指摘はチャットや表計算
  • 字幕修正だけ別ツール・別履歴
  • 確定内容を編集側がNLEへ再入力

Proposed flow

確認から受け渡しまで、ひとつの時間軸で

01 SOURCEDropbox動画を直接再生
02 REVIEWコメント・指示一点／範囲で記録
03 CAPTION字幕修正話者・行・遅延も保持
04 HANDOFFNLE・処理基盤CSV / XML / JSON

Boundary

判断は人に、転記と反復は機械に

事実確認、表現、採否、最終承認は人が担います。時刻・状態の保持、一覧化、書式変換、外部処理との接続を機械化します。

Small pilot

一つの制作単位で、減る手間を測る

検証する流れ

  • 非機密の映像1本を登録
  • 複数担当者がレビュー
  • 字幕を同じ時間軸で承認
  • DaVinci向けに書き出し

見る指標

指摘回収時間再入力回数 見落とし件数修正の往復数

業務利用に関する前提

現状は小規模チーム向け試作です。本番データ投入前に、安全な共有リンク、認証・権限、変更競合、版管理、監査ログの実装が必要です。 完成済みのFrame.io代替ではなく、Dropboxを起点にしたレビュー基盤の検証対象です。
